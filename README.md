# 🚗 Mobilidade Acessível - Protótipo de Interface por Voz

Aplicação web focada em acessibilidade para facilitar a solicitação de viagens por aplicativo para idosos e pessoas com dificuldades de digitação.

## 🎯 Problema Resolvido
Idosos frequentemente encontram barreiras ao digitar endereços em interfaces móveis padrão, resultando em erros de rota e frustração.

## ✨ Funcionalidades
- **Reconhecimento de Voz:** Captura rápida do endereço usando a Web Speech API nativa.
- **Leitura Sonora (Text-to-Speech):** O sistema lê o destino de volta para confirmação auditiva.
- **Design Adaptado:** Botões com área de toque ampliada e alto contraste visual.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (Flexbox, CSS Variables e Animações)
- JavaScript (Vanilla JS + Web Speech API)
